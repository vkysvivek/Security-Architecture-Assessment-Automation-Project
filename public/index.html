1  Submit the architecture package every zone is optional

The six minimum requested inputs for a Security Architecture Review. Each zone takes a file or a document link — SharePoint, Confluence, a wiki page, anywhere the artifact lives. What the agent can read is assessed against good security architecture practice; anything left empty is reported as a missing input with a priority. Neither stops the review from running. PNG, JPEG, WebP, GIF, PDF, or text formats (Markdown, JSON, YAML, XML, .drawio, Mermaid, Terraform). Office files should be exported to PDF first.

Links are recorded, not opened. The agent runs in your browser and has no access to your SharePoint session, so it cannot fetch a link's contents. A link is logged in the Evidence Source Register exactly as you paste it and the input is assessed as not provided — the same as leaving the zone empty. Upload the file itself if you want it assessed.
